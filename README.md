# 价脉 Price Pulse · 手机市场行情监控看板

面向手机回收与竞拍业务的市场价格监控原型。看板围绕“市场是否在变、哪个品牌在变、哪个机型在变、数据是否可信”组织信息，支持按日报价快照查看全量机型与 TOP100 重点机型的相对价格变化。

## 已实现能力

- 7 个业务日期切换：`2026-10-27` 至 `2026-11-02`，所有指标随日期重算。
- 全量与 TOP100 双口径：全量覆盖 891 款在榜机型；TOP100 为固定重点池，单独计算指数、品牌结构与涨跌。
- 目标池进度：目标 1,000 款，当前在榜 891 款，缺口 109 款进入运营待办，便于继续补齐数据源。
- 五类成色联动：靓机、小花、大花、外爆、内爆；指数、品牌排行、热力和机型榜保持同一筛选口径。
- 市场行情总览：中位数价格指数、SKU 涨跌结构、异常跳价统计、当日报价覆盖率。
- 7 日行情简报：按当前日期、范围、成色自动生成市场方向、涨跌广度、品牌强弱、异动、数据质量与 P0/P1/P2 行动建议；支持一键复制纯聚合结论，便于直接发群或写入日报。
- 品牌监控：品牌 × 成色涨跌热力，以及显式展示上涨 / 下跌 / 持平数量、下跌占比和可比样本的品牌涨跌广度榜；少于 5 条可比样本时标记“样本不足”。
- 价格结构分析：主配置口径的日涨跌九档分布与六段价格带，展示有效样本、隔离异常、涨跌构成和各价格带中位变化；不把演示内存阶梯混入分布结论。
- 固定队列趋势：固定选取当前成色 7 日连续有价的同一批机型，按每日中位涨跌复利形成队列指数，并与同成色市场指数并列比较；队列不随日期洗牌，避免新进/退出样本改变趋势。
- 机型监控：搜索、品牌筛选、有效涨跌/有效涨幅/有效跌幅/异常跳价/价格/池内名次排序、加载更多、CSV 导出；榜单说明随当前排序同步。
- 买家报价：详情支持切换具体内存、成色和任意报价矩阵单元；展示近 7 日中位价、P25–P75、有效样本、价格位置与振幅，并可复制摘要、关注 SKU、导出当前 SKU 明细。
- 机型详情：价格趋势、内存 × 成色矩阵、期内累计变化、数据覆盖与重点池名次；所有价格明确标注“参考价，非成交价”。
- 运营待办：动态生成异常跳价、机型异动、品牌脉动、数据缺口、目标池缺口和三档成色同价任务；支持跳转筛选、打开机型与本地记录核验状态。
- 数据质量提醒：当所选内存的靓机、小花、大花当前同价，或完整 7 日序列完全一致时，在详情和待办中提示先复核成色映射与源报价。
- 数据体检：7 日有效报价、两日匹配率、内存缺失、异常跳价和每日覆盖率时间线。
- 响应式布局：1440px 桌面端与 390px 移动端均无横向页面溢出；移动端机型表压缩为核心价格字段。
- 可访问性：键盘操作、焦点恢复、抽屉 `inert` 隔离、图表和横条区域语义；axe 扫描为 0 个违规项。

## 数据口径

- 数据窗口：7 个自然日报价快照。
- 实际去重机型：**891 款**。这是数据源的真实数量，因此页面如实展示 891，而不是虚标 900+。
- 7 日有效报价：**65,040 条**；7 日唯一键总数：**78,380 条**；差额为未补价记录。
- 最新日 2026-11-02：原始唯一键 13,020 条，有价 9,765 条，零价 3,255 条，有价率 75.0%。
- TOP100 重点池：近 7 日靓机连续有价，按最新靓机市场价从高到低取前 100 款，7 天内固定不重新洗牌。
- 唯一键：`日期 + 机型ID + 内存 + 成色`；同一天同一 SKU 不允许多个价格。
- 当前演示数据共 891 款机型、2,604 个内存配置，其中 818 款为多配置机型；配置数量与机型 `configCount` 已做一致性校验。
- 内存缺失记录不进入机型比较；7 天共 20 条，页面单独披露。
- 指数只比较相邻两日同一 SKU，使用非零涨跌中位数；新增、退出、零价和缺失日不当作涨跌。
- 单日涨跌超过 ±30% 视为异常跳价，不进入指数、品牌热力与有效波动排序，保留在异常统计和“异常跳价优先”排序中。
- 品牌或成色可比样本少于 5 条时，不输出强弱结论。
- 靓机、小花、大花完整 7 日序列一致并不直接视为业务结论；当前全量 498 款、TOP100 62 款，均进入“成色映射”运营待办。
- 公网数据为脱敏演示值；真实涨跌结构、样本量、异常比例和 891/100 的数量口径保持不变。
- 当前仅主配置使用真实脱敏行情，其他内存配置是按可见阶梯生成的演示数据；页面会显式提示，不能据此判断真实内存价差。
- 涨跌分布与价格带只使用主配置报价；“全部成色”汇总五类成色观察，同一机型可有多成色记录，不能把观察条数当作机型数。
- 固定队列只使用主配置报价；当前筛选为“全部”时明确采用靓机固定队列，不与全内存 SKU 广度混读。
- 固定队列只在 7 日全有价的同一批机型内计算每日中位涨跌，再复利形成指数；不以归一化后的绝对价格中位数代替，避免高价样本和异常跳价拉偏。

## 数据生成

从本地报价单生成真实数据到临时文件：

```bash
python3 generate_data.py /tmp/price-pulse-real.js /path/to/报价单_1.xlsx ... /path/to/报价单_7.xlsx
```

再生成可公开的脱敏版本：

```bash
python3 prepare_public_data.py /tmp/price-pulse-real.js assets/data.js
```

如临时只有主配置真实行情，可用 `enrich_demo_configs.py` 补齐演示配置阶梯；生成结果会标记 `configDataMode = "synthetic-demo"`，不会冒充真实多内存报价。

`assets/data.js` 在仓库中必须是脱敏版本。`prepare_public_data.py` 会拒绝重复处理已脱敏文件；原始报价单、真实价格导出文件和凭证均不得提交到仓库。

## UI 自检结论

符合市场价格监控场景的核心判断：

- 涨跌色符合国内行情习惯：红涨、绿跌，异常使用琥珀色单独提示。
- 首屏先给指数与涨跌结构，再给品牌和机型下钻，信息顺序符合“先判断市场，再定位原因”。
- 全量与 TOP100 分离，避免重点机型掩盖全量长尾价格变化。
- 异常跳价主动隔离，不把脏价格包装成暴涨暴跌。
- 日期、范围、成色、品牌筛选共用统一状态，图表、热力、榜单和详情口径一致。
- 零价、缺失、新增/退出与匹配率显式披露，避免“没报价”被误判为降价。
- 运营待办按“发现 → 定位 → 核验”闭环组织，任务可直接落到筛选、机型详情或数据体检，减少看板到 Excel 的来回切换。
- 买家报价把中位价、区间、样本和振幅放在当前价旁，并明确参考价边界，避免把行情报价当成成交承诺。
- 内存 × 成色矩阵支持横向浏览和键盘操作，移动端不压缩价格列，保证报价单元可读。
- 7 日简报先给结论，再把“发生了什么”拆到涨跌广度、品牌、价格带和固定队列；运营可按 P0→P1→P2 进入待办或筛选，买家可从机型详情读取参考价与波动区间，两个视角不混淆。
- 分布与价格带使用横向条形和数字标签，不依赖颜色单一编码；固定队列同时展示队列指数与市场指数，避免把“队列没动”误读成“市场没动”。

仍需在正式接入阶段补齐的能力：

- 日更批次的失败告警、迟到数据和上游回调状态。
- 接入真实多内存报价，替换当前非主配置的演示阶梯，并校验配置命名与机型映射。
- 历史任意日期区间与同环比自定义窗口。
- 价格异常的人工复核、备注、处置状态和审计记录。
- 真实业务权限、数据水印、下载审批和操作日志。
