# 价脉 Price Pulse · 手机市场行情监控看板

面向手机回收与竞拍业务的市场价格监控原型。看板围绕「市场是否在变、哪个品牌在变、哪个 SKU 在变」组织信息，支持按日查看价格变化，并下钻到机型、内存和成色。

## 已实现

- 市场基准指数与五类成色指数切换，支持 7D / 30D 周期。
- 品牌 × 成色涨跌热力图，点击任意色块联动筛选机型榜。
- 品牌日涨跌排行，随成色筛选动态重算。
- 机型异动榜：搜索、品牌筛选、成色筛选、排序、加载更多、CSV 导出。
- 机型详情抽屉：成色切换、30 日价格趋势、成色价格阶梯、7 日 / 30 日变化。
- 数据体检区块与指标口径说明弹窗。
- 适配桌面、平板和移动端；支持键盘操作与减少动效偏好。

## 数据说明

- 数据源为 2026-11-02 的报价单结构，包含 891 个机型、13,020 条 `机型 + 内存 + 成色` 记录。
- 原始报价中有 3,255 条零价，原型将其定义为「待补价」，不进入涨跌计算。
- 页面价格在原始报价基础上做了轻微扰动，趋势为模拟数据，仅用于 UI 评审，不代表真实行情。
- 原始 Excel 文件未包含在本目录和公开站点中。
- 正式接入时应以 `日期 + 机型ID + 内存 + 成色` 为唯一键，每天保存不可变快照；零价、缺失和 Top1000 退出均不当作降价。
