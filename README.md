# 价脉 Price Pulse · 手机市场行情监控看板

面向手机回收与竞拍业务的市场价格监控原型。看板围绕“市场是否在变、哪个品牌在变、哪个机型在变、数据是否可信”组织信息，支持按日报价快照查看全量机型与 TOP100 重点机型的相对价格变化。

## 已实现能力

- 7 个业务日期切换：`2026-10-27` 至 `2026-11-02`，所有指标随日期重算。
- 全量与 TOP100 双口径：全量覆盖 891 款在榜机型；TOP100 为固定重点池，单独计算指数、品牌结构与涨跌。
- 五类成色联动：靓机、小花、大花、外爆、内爆；指数、品牌排行、热力和机型榜保持同一筛选口径。
- 市场行情总览：中位数价格指数、SKU 涨跌结构、异常跳价统计、当日报价覆盖率。
- 品牌监控：品牌 × 成色涨跌热力，以及按日涨跌排序的品牌强弱榜；少于 5 条可比样本时标记“样本不足”。
- 机型监控：搜索、品牌筛选、有效涨跌/有效涨幅/有效跌幅/异常跳价/价格/池内名次排序、加载更多、CSV 导出；榜单说明随当前排序同步。
- 机型详情：主配置价格趋势、成色切换、价格阶梯、期内累计变化、数据覆盖与重点池名次。
- 数据体检：7 日有效报价、两日匹配率、内存缺失、异常跳价和每日覆盖率时间线。
- 响应式布局：1440px 桌面端与 390px 移动端均无横向页面溢出；移动端机型表压缩为核心价格字段。
- 可访问性：键盘操作、焦点恢复、抽屉 `inert` 隔离、图表和横条区域语义；axe 扫描为 0 个违规项。

## 数据口径

- 数据窗口：7 个自然日报价快照。
- 实际去重机型：**891 款**。这是数据源的真实数量，因此页面如实展示 891，而不是虚标 900+。
- 7 日有效报价：**65,040 条**；7 日唯一键总数：**78,380 条**；差额为未补价记录。
- 最新日 2026-11-02：原始唯一键 13,020 条，有价 9,765 条，零价 3,255 条，有价率 75.0%。
- TOP100 重点池：近 7 日靓机连续有价，按最新靓机市场价从高到低取前 100 款，7 天内固定不重新洗牌。
- 唯一键：`日期 + 机型ID + 内存 + 成色`；同一天同一 SKU 不允许多个价格。
- 内存缺失记录不进入机型比较；7 天共 20 条，页面单独披露。
- 指数只比较相邻两日同一 SKU，使用非零涨跌中位数；新增、退出、零价和缺失日不当作涨跌。
- 单日涨跌超过 ±30% 视为异常跳价，不进入指数、品牌热力与有效波动排序，保留在异常统计和“异常跳价优先”排序中。
- 品牌或成色可比样本少于 5 条时，不输出强弱结论。
- 公网数据为脱敏演示值；真实涨跌结构、样本量、异常比例和 891/100 的数量口径保持不变。

## 数据生成

从本地报价单生成真实数据到临时文件：

```bash
python3 generate_data.py /tmp/price-pulse-real.js /path/to/报价单_1.xlsx ... /path/to/报价单_7.xlsx
```

再生成可公开的脱敏版本：

```bash
python3 prepare_public_data.py /tmp/price-pulse-real.js assets/data.js
```

`assets/data.js` 在仓库中必须是脱敏版本。`prepare_public_data.py` 会拒绝重复处理已脱敏文件；原始报价单、真实价格导出文件和凭证均不得提交到仓库。

## UI 自检结论

符合市场价格监控场景的核心判断：

- 涨跌色符合国内行情习惯：红涨、绿跌，异常使用琥珀色单独提示。
- 首屏先给指数与涨跌结构，再给品牌和机型下钻，信息顺序符合“先判断市场，再定位原因”。
- 全量与 TOP100 分离，避免重点机型掩盖全量长尾价格变化。
- 异常跳价主动隔离，不把脏价格包装成暴涨暴跌。
- 日期、范围、成色、品牌筛选共用统一状态，图表、热力、榜单和详情口径一致。
- 零价、缺失、新增/退出与匹配率显式披露，避免“没报价”被误判为降价。

仍需在正式接入阶段补齐的能力：

- 日更批次的失败告警、迟到数据和上游回调状态。
- 历史任意日期区间与同环比自定义窗口。
- 价格异常的人工复核、备注、处置状态和审计记录。
- 真实业务权限、数据水印、下载审批和操作日志。
